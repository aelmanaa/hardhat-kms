# hardhat-kms

> Work in progress. Not published to npm yet.

Hardhat 3 plugin to sign transactions, messages and typed data with keys held in **AWS KMS**,
**GCP Cloud KMS** and **Azure Key Vault / Managed HSM**. Private keys never leave the KMS/HSM.

See [`docs/DESIGN.md`](docs/DESIGN.md) for the design and roadmap, and [`CONTRIBUTING.md`](CONTRIBUTING.md) to develop.
