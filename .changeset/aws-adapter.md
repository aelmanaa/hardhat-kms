`@hardhat-kms/aws` is the AWS KMS provider. It checks that the key is a secp256k1 signing key and signs with the key ARN. It depends on `@aws-sdk/client-kms` 3.1143.0 or later. There is no SDK to install separately.

Issue: [#16](https://github.com/aelmanaa/hardhat-kms/issues/16)
