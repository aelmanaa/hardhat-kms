0.9.0 is the first published version of hardhat-kms and of the `@hardhat-kms/aws`, `@hardhat-kms/gcp` and `@hardhat-kms/azure` providers. It is the release candidate for 1.0.0. The maintainer installs 0.9.0 from npm and runs it against AWS KMS, Google Cloud KMS and Azure Key Vault; 1.0.0 is the 0.9.x that passes, with only the version number changed. Until 1.0.0 is published, use 0.9.0 with test keys on testnets.
